## About the role

FinTaxTech builds new websites and complete redesigns for small businesses. We are looking for a Web Developer who can take a client site from a scoped brief through launch and build the integrations that support it. A project might include a booking tool, a conditional enquiry form or a questionnaire that generates a branded PDF.

## What you will work on

- Build responsive client sites in Astro and TypeScript using reusable layouts and structured content.
- Connect enquiry forms to email or approved third-party services and integrate booking tools where the project calls for them.
- Build and test form validation, error states and document generation. Collect only the data needed for the agreed workflow.
- Set up metadata, redirects and sitemaps for launches and rebuilds.
- Test the complete user journey, including keyboard navigation, mobile layouts and successful delivery of an enquiry.
- Support deployment, domain setup and handover, and document how to operate the site and its integrations.

## You will be working on

- Semantic HTML, responsive CSS, TypeScript and an understanding of browser behaviour.
- Astro or experience delivering static sites with reusable components and structured content.
- Form validation, HTTP APIs and practical experience with server-side JavaScript.
- Git, automated browser testing and deployment troubleshooting.
- Accessibility, performance and technical SEO for production websites.

Experience building Node.js services, generating PDFs with jsPDF or testing with Playwright or Vitest would be useful. Familiarity with GitHub Actions, analytics consent or DNS configuration is also welcome.

## How we approach the work

Confirm how the site should work before implementation. Review progress in a preview and check what the client and their customers will experience on the deployed site before handover.
