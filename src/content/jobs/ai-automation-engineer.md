## About the role

FinTaxTech builds AI workflows for repeatable business tasks. We are looking for an AI Automation Engineer who can take a workflow from a written brief through implementation, testing and handover. Our work includes qualifying leads and generating personalised letters, turning articles into branded social posts, and connecting those workflows to the tools people already use.

## What you will work on

- Map workflow inputs, decisions, outputs and review points with the people who will use the automation.
- Build scheduled and on-demand workflows in Python and connect them to business tools through APIs and webhooks.
- Write and test model instructions for research, extraction and drafting. Validate structured outputs before passing them to another system.
- Build in deduplication, safe retries and approval steps so a failed run can be resumed without creating duplicate records or posts.
- Add run summaries, failure alerts and dry runs. Keep publishing credentials in the systems that need them.
- Document how to run, review and maintain each workflow.

## You will be working on

- Python, REST APIs, webhooks and structured data such as JSON.
- Experience integrating an LLM into a multi-step workflow and testing its outputs against realistic inputs.
- Automated testing, error handling and debugging across several connected systems.
- Git and secure handling of credentials and access permissions.

Experience with FastAPI or Claude and other LLM APIs would be useful. Familiarity with n8n, Make or Zapier, GitHub Actions, Slack integrations, the Meta Graph API or HTML-to-PDF generation is also welcome.

## How we approach the work

Agree what a correct result looks like before building. Use realistic examples to test failure cases and give the person running the workflow enough information to review an output or investigate a failed run.
