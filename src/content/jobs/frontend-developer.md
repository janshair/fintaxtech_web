## About the role

FinTaxTech builds websites, mobile apps, brand identities and AI-assisted workflows. We are looking for a Front-End Developer to help turn clear requirements into reliable, accessible website experiences.

Our website uses Astro and TypeScript, with Markdown content collections, shared layouts and components, and centralised text and design constants. It generates static pages for GitHub Pages. Interactive questionnaires keep answers in browser memory and generate enquiry PDFs locally.

The role is remote or based in Dundee, Scotland. The work calls for care with usability, privacy and maintainability, as well as how a page looks.

## What you will work on

- Build and maintain responsive pages using semantic HTML, modern CSS, JavaScript and TypeScript within Astro.
- Extend reusable components and shared layouts, keeping content, business rules and design constants separate.
- Maintain Markdown articles and other structured content through validated Astro content collections.
- Make interfaces accessible, including logical headings, labelled inputs, visible keyboard focus and useful validation messages.
- Implement technical SEO, canonical URLs, sitemap entries and accurate structured metadata in generated HTML.
- Improve loading performance through careful use of images, fonts and browser-side code.
- Work with Git and GitHub, review changes and support static deployment to GitHub Pages.
- Use Vitest and Playwright to check business logic, user journeys and behaviour across browsers and screen sizes.

## Skills you will use

- Semantic HTML and modern CSS, including responsive layouts.
- JavaScript and TypeScript, with an understanding of browser behaviour.
- Astro, Markdown and Astro content collections.
- Accessibility and keyboard-friendly interface design.
- Technical SEO and structured metadata.
- Git and GitHub for version control and collaboration.
- GitHub Pages and the constraints of static deployment.
- Node.js and pnpm for local development, dependency management and build commands.
- Vitest for automated unit tests and Playwright for browser tests.
- Performance measurement and cross-browser testing.
- Reusable components and centralised content and design constants.

## Useful additional familiarity

Experience with jsPDF for browser-side PDF generation and image optimisation would be useful, but neither is mandatory. Our current website does not use React, so React experience is not required.

## How we approach the work

We value clear communication, small reviewable changes and checking the generated website as well as its source code. You should be comfortable explaining implementation choices, raising unclear requirements and testing changes before they are published.
