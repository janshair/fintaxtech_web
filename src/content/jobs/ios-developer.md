## About the role

FinTaxTech builds native iOS apps for practical tasks such as invoicing and document creation. We are looking for an iOS Developer who can implement accessible SwiftUI interfaces, test business rules and take a build through TestFlight and App Store submission preparation.

## What you will work on

- Build SwiftUI screens and reusable components for iPhone and iPad, with support for Dynamic Type and VoiceOver.
- Implement local-first features with SwiftData and test migrations where the data model changes.
- Build and test business rules, including calculations, validation and PDF generation for document-heavy apps.
- Integrate system features such as sharing and file export, and add subscription flows where the product calls for them.
- Maintain build configurations and signing, prepare TestFlight builds and support App Store Connect submissions.

## You will be working on

- Swift, SwiftUI and Swift concurrency.
- SwiftData or Core Data and an understanding of data migrations.
- Xcode, Swift Package Manager and Git.
- Automated tests with Swift Testing or XCTest.
- Experience with code signing, TestFlight or App Store Connect.

Experience with PDFKit or Core Graphics would be useful for document work. Familiarity with StoreKit 2 or RevenueCat, Firebase, localisation or release automation with GitHub Actions is also welcome.

## How we approach the work

Keep business rules independently testable and review the full user journey on representative devices. Check accessibility, data persistence and export behaviour as part of release preparation.
