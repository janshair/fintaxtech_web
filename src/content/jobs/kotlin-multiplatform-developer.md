## About the role

FinTaxTech uses Kotlin Multiplatform to share business rules, persistence and feature state across Android and iOS. Our apps use Jetpack Compose on Android and SwiftUI on iOS. We are looking for a developer who can build and test the shared layer and follow a feature through to both platform interfaces.

## What you will work on

- Build shared Kotlin modules for domain logic, persistence and feature state.
- Expose shared state and actions to Swift and handle lifecycle and platform-specific behaviour at the integration points.
- Implement or update the corresponding screens in Jetpack Compose and SwiftUI.
- Maintain offline-first storage and test schema migrations, import and export, and other behaviour that affects existing user data.
- Run shared tests and verify complete user journeys on Android and iOS.
- Support Gradle and Xcode build configurations and CI checks for both platforms.

## You will be working on

- Kotlin, coroutines, Flow and Kotlin Multiplatform source sets.
- Experience integrating a shared Kotlin module into Android and iOS apps.
- Ability to work with Jetpack Compose and read and update SwiftUI code.
- Local persistence, automated testing, Gradle and Git.
- Debugging across shared Kotlin, Android and Swift code.

Experience using Room or SQLite in a multiplatform project would be useful. Familiarity with Koin, Xcode build configurations, GitHub Actions or mobile store release workflows is also welcome.

## How we approach the work

Agree what behaviour both platforms should share, then verify how each platform presents it. Keep platform-specific decisions easy to locate and test shared rules where they are implemented.
