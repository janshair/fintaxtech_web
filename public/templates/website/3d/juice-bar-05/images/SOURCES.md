## Optional cut-outs to generate

Each file below: PNG or lossless WebP, 1024 × 1024 pixels, transparent background, isolated single object, generous clear margins, soft studio light from upper left, no lettering, no cast ground shadow. Keep a consistent camera/perspective and colour balance. Downsize production sprites to 256–512 px and compress before adoption; total shipped 3D assets must remain ≤1.5 MB.

| Files | Subject and views |
| --- | --- |
| strawberry-1, strawberry-2, strawberry-3 | One ripe strawberry with calyx: front three-quarter; side three-quarter; top showing calyx. |
| orange-slice-1, orange-slice-2, orange-slice-3 | One fresh circular orange slice: face-on; tilted 25° left; tilted 25° right, visible rind thickness. |
| leaf-1, leaf-2 | One fresh small mint leaf: face-on with visible veins; three-quarter with gentle natural curl. |
| coffee-bean-1, coffee-bean-2, coffee-bean-3 | One roasted coffee bean: crease face-on; crease in three-quarter; rounded reverse side. |
| ice-1, ice-2 | One clear rounded ice cube: front three-quarter; rotated 45° three-quarter; readable translucent edges, no baked background. |

When supplied, record each final filename, exact generator/source, creation date and applicable licence here before using it. There are currently no cut-outs to wire into the renderer; the existing one-InstancedMesh bean system remains in use.

The `*-sleeve-mask.webp` and `*-text-mask.webp` files in the parent directory are original capture masks from the same procedural renderer, generated by `_checks/capture.mjs`. They selectively theme the poster sleeves, branded straw and neutral marks while leaving physical objects untouched. Source: this repository; licence: same as the original project artwork.
