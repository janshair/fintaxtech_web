# Rules for AI assistants working in this repository

## Git

- Never add Codex, Codex or any other LLM or AI tool as an author or
  co-author when committing or pushing. No `Co-Authored-By:` trailers for AI
  tools, no "Generated with" lines in commit messages or pull request
  descriptions, and no AI author or committer identity. Commits use the
  repository's configured git user only.
- Do not create separate git worktrees. Work in the main worktree
  (this folder) only, including for parallel or background sessions.
